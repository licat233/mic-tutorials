# 中国制造网运营 AI Agent 知识库

用途：给其它 AI agent 做可检索、可追溯的知识库。这个版本不是只给人看的精简笔记，而是同时保留总纲、逐篇课程正文、常用文档提取文本和 JSONL 切片。

## 使用方式

1. 先读 `00_总纲学习笔记.md`，建立中国制造网运营框架。
2. 需要回答具体问题时，查 `chunks.jsonl` 或 `课程逐篇/`、`常用文档逐篇/` 中的源文档。
3. 回答涉及规则、阈值、后台路径、权益条件时，优先引用逐篇文档中的原始细节。
4. 如果某篇文档标注“未识别到口播内容”或“未提取到正文”，不要基于标题编造细节。

## 文件结构

- `00_总纲学习笔记.md`：人类友好的总纲和模块化笔记。
- `课程逐篇/`：每个视频 txt 的清洗版正文，保留来源路径。
- `常用文档逐篇/`：Excel/PDF/PPTX 提取文本。
- `chunks.jsonl`：适合导入 RAG/向量库的切片，每行一个 JSON。

- 切片数：425

- `chunks.jsonl` 为纯文本切片，适合检索；如果需要完整上下文，应回看对应逐篇 Markdown。
