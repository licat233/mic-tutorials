## 与原始资料的关系

- `已经学过了/`：原始课程、MIC 帮助中心资料和常用文档，是来源层。
- `中国制造网运营_AI_Agent知识库/`：偏逐篇学习、切块和 Agent 检索的数据层。
- 本目录：偏“运营方法论 + 任务路由 + 诊断框架”的精炼知识层。

本目录不会替代原始资料。涉及当前费用、广告位、星级评分阈值、国家/区域、禁限售、交易费率、支付规则、UI 字段或平台政策时，应优先核对 MIC 当前官方页面。

## 知识优先级

1. 当前 MIC 实际页面、实时账号数据与官方最新规则；
2. 本目录中整理后的稳定运营方法；
3. `已经学过了/` 中的课程、帮助中心快照和经验材料；
4. 一般经验或模型知识。

旧课程、旧截图和历史 UI 不能覆盖更新后的平台规则。

## 默认运营诊断模型

先看漏斗，再决定动作：

`曝光 → 访问 → 询盘/TM咨询 → 回复与跟进 → 成交`

- 曝光不足：查目录精准性、搜索匹配、产品覆盖、产品/供应商质量、主打资源、广告与市场需求。
- 曝光正常但访问低：查首图、标题、搜索结果相关性、属性/价格展示和竞争力。
- 访问正常但询盘低：查详情页、价值表达、信任证据、公司实力和市场匹配。
- 询盘正常但转化低：查响应速度、询盘状态、负责人分配、需求理解、报价和持续跟进。

## 使用原则

这套知识库的目的不是让运营人员机械执行“多发产品、多塞关键词、多买广告”，而是让 MIC 运营基于买家需求和数据证据形成闭环：

`发现问题 → 找到漏斗阶段 → 确认证据 → 采取单一可验证动作 → 观察结果 → 继续优化`
