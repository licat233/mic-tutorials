# MIC 运营知识总览

## 目标

这套知识用于 MIC 账号诊断、自然流量、发品质量、供应商星级、数据罗盘、广告投放、询盘与 Trade Messenger、RFQ/主动营销、在线交易以及 AI 麦可等运营工作。

## 核心原则

### 1. 买家导向，而不是供应商自嗨

MIC 搜索和推荐的本质是帮助买家更准确地找到产品。运营首先要保证：

- 产品是什么表达清楚；
- 类目准确；
- 名称、属性、关键词一致；
- 产品信息能帮助买家判断；
- 公司和供应能力有可信证据。

### 2. 先诊断漏斗，再决定动作

默认从：

`曝光 → 访问 → 询盘/TM咨询 → 回复/跟进 → 成交`

逐层查问题。

不要一看到数据下降就直接：
- 改标题；
- 加更多关键词；
- 批量发品；
- 买广告。

### 3. 自然流量与付费流量分开分析

广告可以买到更确定的展示机会，但不能修复：
- 产品不相关；
- 标题不清晰；
- 首图差；
- 详情页转化差；
- 商机回复慢。

### 4. 平台规则与产品事实分开

MIC 平台规则说明“平台怎么要求、怎么匹配、怎么统计”，但不能证明某个产品的真实规格、认证、功率、MOQ、价格、交期或质保。

产品事实必须来自企业自己的真实资料。

## 运营问题路由

| 问题 | 优先阅读 |
|---|---|
| 搜不到、排名下降、自然曝光低 | 01 搜索与自然排名 |
| 产品曝光有但点击/访问少 | 02 产品发布与信息质量 + 04 数据诊断 |
| 星级低、账号基础差 | 03 供应商星级 |
| 不知道数据哪里出问题 | 04 数据罗盘 |
| TopRank/精点投效果差 | 05 广告与数智营销 |
| 询盘多但回复/转化差 | 06 询盘与 TM |
| RFQ 报价效率低 | 07 RFQ 与主动营销 |
| 订单、付款、退款等 | 08 在线交易 |
| AI 麦可能做什么 | 09 AI 麦可功能地图 |

## 最重要的运营闭环

每次优化都应能回答：

`问题发生在哪一层 → 证据是什么 → 改什么 → 用哪个指标验证`

如果无法回答这四个问题，通常说明动作仍然停留在“经验猜测”，而不是数据运营。
