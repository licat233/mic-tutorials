中国制造网素材库二期上线
中国制造网素材库二期上线

素材库功能：方便高级会员管理各种展示资源，大容量，一次上传，全站通用。

为了方便会员朋友的使用，我们在2017年12月进行了素材库的全面升级，一起来看看详细操作吧！ 

功能升级：

✔ 新增图片删除功能

✔ 新增产品编辑页上传的图片，系统自动同步至素材库功能

✔ 新增视频管理功能

✔ 二期素材库，将会成为图片、视频、动图、全景图、全景看厂五种素材管理的中心

 

一、图片

1、新增“系统同步”标签

✓  素材库二期上线后，供应商本地新上传/编辑产品表单的图片（含描述中的），系统将会自动同步至素材库“系统同步”标签下

✓   图片同步时，本地新上传的图片保留原图片名称（即本地上传的图片名称，注意非产品名称），编辑的图片统一命名为prodphotoprodphoto，您可在素材库中对图片进行重命名。

✔  素材库删除图片和产品编辑页面删除图片互不影响。

例1：产品图片A已系统同步到素材库，之后您在素材库删除了图片A，产品详情页仍会正常显示图片A，不会自动删除；

例2：产品图片B已系统同步到素材库，之后您在素材库删除了图片B，如您再次将图片B上传至产品编辑页面，图片B将会再次同步到素材库

例3：产品图片C已系统同步至素材库，您在产品编辑页面删除了图片C，素材库将仍然保留图片C，不会自动删除

 

✓  一期素材库及二期素材库期间（即9.27-12.12）新上传的图片，最迟将于3月15日前全部同步至素材库

 

2、上传图片增加自动校验及提示

✓  在素材库点击“上传图片”时，一次性最多可上传50张图片，仅支持JPG/JPEG格式、RGB模式且图片小于5MB

✓  如上传的图片与“我上传的”、“系统同步”、“上门拍摄”三个标签下已有图片重复，则上传失败，并提示重复图片

3、新增图片删除功能

操作：勾选单张或多张图片，点击“删除”

✓  仅“我上传的”和“系统同步”分组下的图片可以删除，其中主帐户可以删除所有本地上传和系统同步的图片，子帐户仅可以删除自己手动上传至素材库的图片

✓  选择删除后，如果您再次将图片上传至产品表单，图片将会被再次同步

✓  成功删除“我上传的”标签下的图片时，素材库将会自动释放相应的存储空间

4、图片分组增加快捷操作

✓  输入组名后，点击enter键即可便捷完成组的创建

✓  在二级组或三级组的界面，点击组名关系即可便捷定位相应分组

 

二、视频

1、上传视频

✓  原展示厅企业风采栏目下的“My Video”视频管理功能迁移至素材库，展示厅企业风采栏目下不再显示“My Video”

提醒：如果您之前将“My Video”栏目设置成展示厅首页显示，素材库二期上线后，首页显示的Company Show将不再展示，建议您及时进入展示厅完善

✓  视频上传入口：网站建设>>素材库>>视频>>上传视频

✓  主帐户和有信息管理权限的子帐户，均可在素材库中上传/编辑/删除视频

✓  每个高级会员视频库有2个G的容量

✓  视频上传的格式为3gp, avi, asf, mov, mpg, mpeg, mp4, m4v, mkv，单个视频大小不超过50MB

✓  之前已上传的视频自动迁移至素材库中

2、编辑视频

✓  视频上传后（包括购买的Onsite Video），中国制造网会进行审核，只有通过审核且被引用的视频才可以在展示厅中展示

✓  第三方拍摄的视频由中国制造网协助上传，在视频列表中带有Onsite Video标识，此类视频仅可编辑标题，不可删除

✓  您自主上传的视频，可进行编辑（重新上传/更改标题/更改类别）或删除，点击视频可以查看到视频的“最后操作人”、“审核状态”、“更新日期”、“关联产品数”

✓  如您仅修改了视频类型，则不影响审核状态；如您重新上传视频或更改标题，视频将重新进入视频审核队列

✓  编辑视频，不会改变视频和产品的关联关系

3、引用视频

✓  只有被引用且通过审核的视频才可以在展示厅中展示

✓  产品引用视频的操作：网站建设>>已发布的产品/添加产品，进入产品编辑页面后，在产品展示处，勾选需要引用的视频，点击“确定”即可

✓  展示厅公司场景引用视频的操作：网站建设>>管理展示厅>>编辑展示厅>>公司场景处，点击“选择视频”>>勾选需要引用的视频，点击“确定”
